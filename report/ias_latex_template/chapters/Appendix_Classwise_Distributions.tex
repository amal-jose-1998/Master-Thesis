\chapter{Class-Wise Distribution Plots}
\label{appendix:classwise_plots}

This appendix provides class-wise versions of the main kinematic and trajectory-level variability distributions used in the exploratory data analysis. 
The plots separate cars and trucks in order to make the class-dependent differences in scale and spread more explicit.
